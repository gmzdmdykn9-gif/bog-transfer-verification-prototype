BOG UI

Empty State

Open in Figma ↗

Centered message for screens with nothing to show yet, after errors or after success: status icon (or your own visual), title, description and an optional button.

Usage

<div class="bog-empty" data-type="info">
  <p class="bog-empty__title">No transactions yet</p>
  <p class="bog-empty__desc">Your payments will appear here.</p>
  <div class="bog-empty__actions"><button class="bog-btn" data-type="neutral">Make a payment</button></div>
</div>

<div class="bog-empty" data-type="custom">

</div>
