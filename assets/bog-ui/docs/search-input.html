BOG UI

Search Input

Open in Figma ↗

Search field with leading search icon, clear button and Cancel. Page or Overlay placement, Small or Large.

Usage

<div class="bog-field bog-search">
  <label class="bog-field__box">
    <span class="bog-field__text">
      <span class="bog-search__icon"></span>
      <input class="bog-field__input" type="search" placeholder="Search" enterkeyhint="search">
    </span>
    <button type="button" class="bog-field__clear" aria-label="Clear"></button>
  </label>
  <button type="button" class="bog-search__cancel">Cancel</button>
</div>
<!-- data-size="large" (56px) · data-placement="overlay" (white + shadow) · data-state="skeleton" -->
<!-- Cancel fires "searchcancel" on .bog-search; listen to "input" on the field to filter results -->

Try it

Tap the field: the border appears and Cancel slides in. Type to filter the list; the clear button shows as soon as there is text and stays after you leave the field. Cancel (or Esc) empties the field and leaves search.

    Events appear here.

    Overlay placement

    Placement=Overlay: white fill with the Surface-1 shadow, for colored or photo backgrounds. The shadow is replaced by the border while focused.
