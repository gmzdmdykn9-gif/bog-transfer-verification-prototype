Radio Button

Open in Figma ↗

Lets users choose exactly one option from a short set they can compare, like card delivery. Radio button, Radio Button + Label (left or right aligned) and Radio Button Group (vertical, or horizontal for two short options). Error, read-only, disabled and skeleton; Themed and Inverse. For longer lists use Select; to pick several, use Checkbox.

Usage

<fieldset class="bog-radio-group">
  <legend class="bog-radio-group__label">Card delivery</legend>
  <div class="bog-radio-group__options">
    <label class="bog-radio">
      <span class="bog-radio__row">
        <input type="radio" class="bog-radio__input" name="delivery" value="branch" checked>
        <span class="bog-radio__text">
          <span class="bog-radio__title">Pick up at a branch</span>
          <span class="bog-radio__desc">Free · ready tomorrow</span>
        </span>
      </span>
    </label>
    …more options with the same name…
  </div>
  <p class="bog-radio-group__message">You can change this until the card is issued</p>
</fieldset>

<!-- Radio button after the text -->
<label class="bog-radio" data-align="right">…</label>

<!-- Two short options side by side -->
<fieldset class="bog-radio-group" data-direction="horizontal">…</fieldset>

Try it

Pick an option. The new dot grows in with a small overshoot while the ring turns orange; the old one shrinks away. Tap the selected option again to unselect it.

Motion

Selecting an option turns its ring orange in 250 ms while the dot grows from nothing to full size in 333 ms, overshooting a little before it settles. The ring itself doesn't move or scale. Source: Radio button ↗

A radio button view: the ring colour and the dot's scale each get their own animation, so each runs with its own curve.

A composable with two animate*AsState values: the ring colour and the dot scale.

Built into radio.css as CSS transitions. Nothing to call. Unselect is handled by bog-ui.js; turn it off with data-deselectable="false".
