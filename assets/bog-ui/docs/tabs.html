BOG UI

Tabs

Open in Figma ↗

Switch between views of the same screen: Fixed (equal-width) or Wrapped (hug, scrolling) tabs with a sliding orange indicator, keyboard support and tab panels.

Usage

<div class="bog-tabs" role="tablist" aria-label="Accounts">
  <button type="button" class="bog-tab" role="tab" aria-selected="true"  aria-controls="p-cards" id="t-cards">Cards</button>
  <button type="button" class="bog-tab" role="tab" aria-selected="false" aria-controls="p-deposits" id="t-deposits">Deposits</button>
  <button type="button" class="bog-tab" role="tab" aria-selected="false" disabled>Loans</button>
</div>
<div class="bog-tab-panel" role="tabpanel" id="p-cards" aria-labelledby="t-cards">…</div>
<div class="bog-tab-panel" role="tabpanel" id="p-deposits" aria-labelledby="t-deposits" hidden>…</div>

<!-- Type=Wrapped: tabs hug their label and the row scrolls sideways -->
<div class="bog-tabs" role="tablist" data-type="wrapped">…</div>

<!-- Skeleton tab -->
<div class="bog-tab" data-state="skeleton"><span class="bog-skeleton-wave">Tab 1</span></div>

<script>
  document.querySelector(".bog-tabs").addEventListener("tabchange", e => console.log(e.detail.index, e.detail.value));
  BOG.selectTab(tabsElementOrId, 1);   // select from code
</script>

Try it

Click a tab or focus one and use ← → Home End. The indicator slides, the matching panel shows and tabchange fires.
