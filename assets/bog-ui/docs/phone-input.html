Phone Input

Open in Figma ↗

Phone number field: International (country code picker) or National.

Usage

<div class="bog-field bog-phone-input">
  <label class="bog-field__box">
    <button type="button" class="bog-phone-input__country">
      <span class="bog-flag" data-size="20"><img src="bog-ui/assets/flags/ge.svg" alt=""></span>
      <span class="bog-phone-input__code">+995</span>
    </button>
    <span class="bog-field__text">
      <span class="bog-field__label">Phone number</span>
      <input class="bog-field__input" type="tel" inputmode="tel" placeholder="XXX XX XX XX">
    </span>
    <button type="button" class="bog-field__clear" aria-label="Clear"></button>
  </label>
</div>
<!-- The country sheet is built in. To use your own: add data-sheet-open="id" to the button; rows need data-dial and data-flag. -->
<!-- National: same markup without the .bog-phone-input__country button -->

Try it

Tap the flag and code: a Bottom Sheet lists countries with their flag, name and code. Pick one and it's set in the field. The list is built in (bog-ui.js), so you don't write the sheet yourself. Type a number: it's formatted for the selected country (try United States or United Kingdom).
