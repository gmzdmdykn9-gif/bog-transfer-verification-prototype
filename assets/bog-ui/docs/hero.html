BOG UI

Hero Area

Open in Figma ↗

Top-of-screen header: a centered visual (avatar, image, illustration or card), label, title and description, with optional badges, a Feedback message and actions.

Usage

<section class="bog-hero">
  <div class="bog-hero__content">
    <span class="bog-avatar" data-size="64"><img src="photo.jpg" alt=""></span>
    <div class="bog-hero__text">
      <p class="bog-hero__label">Label</p>
      <h1 class="bog-hero__title">Header text</h1>
      <p class="bog-hero__desc">Description</p>
    </div>
  </div>
  <div class="bog-hero__actions">
    <button class="bog-btn" data-type="secondary" data-width="fill">Primary action</button>
    <button class="bog-btn" data-type="ghost" data-size="small">Text action</button>
  </div>
</section>

Variants

Shown at phone width (375px). The Navigation bar that sits above the hero in Figma is a separate component (not built yet).

Gradient backgrounds

data-gradient="peach | mint | green | brown". The colour covers the whole hero, including buttons and action items, and fades out only towards the bottom edge. On the dark ones (green, brown) the hero text turns white; use light content inside (Amount data-color="white", inverse Feedback). Figma marks these as work in progress.
