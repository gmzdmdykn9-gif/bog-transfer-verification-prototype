BOG UI

Action Item

Open in Figma ↗

A 56px circle with a label and optional amount, used for shortcuts like transfers and saved payees. Four kinds: Primary (orange), Secondary (grey), Media (photo) and Avatar (initials). Optional badge and remove button.

Usage

<div class="bog-action-items">
  <div class="bog-action-item" data-type="primary">
    <button type="button" class="bog-action-item__main">
      <span class="bog-action-item__circle"><span class="bog-icon"></span></span>
      <span class="bog-action-item__label">Transfer</span>
      <span class="bog-action-item__amount">0.01 ₾</span>
    </button>
  </div>
  <div class="bog-action-item" data-type="secondary"> … </div>
  <div class="bog-action-item">
    <button type="button" class="bog-action-item__main">
      <span class="bog-action-item__circle"><span class="bog-avatar" data-size="56">NB</span></span>
      <span class="bog-action-item__label">Nino B.</span>
    </button>
    <button type="button" class="bog-action-item__remove" aria-label="Remove"></button>
  </div>
</div>
