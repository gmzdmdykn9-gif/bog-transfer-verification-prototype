Action Item

Open in Figma ↗

A 56px circle with a label and optional amount, used for shortcuts like transfers and saved payees. Four kinds: Primary (orange), Secondary (grey), Media (photo) and Avatar (initials). Optional badge and remove button.

Usage

<div class="bog-action-items">
  <div class="bog-action-item" data-type="primary">
    <button type="button" class="bog-action-item__main">
      <span class="bog-action-item__circle"><span class="bog-icon"></span></span>
      <span class="bog-action-item__label">Transfer</span>
      <span class="bog-action-item__amount">0.01 ₾</span>
    </button>
  </div>
  <div class="bog-action-item" data-type="secondary"> … </div>
  <div class="bog-action-item">
    <button type="button" class="bog-action-item__main">
      <span class="bog-action-item__circle"><span class="bog-avatar" data-size="56">NB</span></span>
      <span class="bog-action-item__label">Nino B.</span>
    </button>
    <button type="button" class="bog-action-item__remove" aria-label="Remove"></button>
  </div>
</div>

Selection strip

Chosen items — like recipients — shown as removable Avatar / Media Action Items in a row above the list they were picked from. The strip opens with the first item, scrolls when it's full and closes when the last one is removed. Try it in the phone on the right: tick people in the list, or tap the red minus on an avatar.

<div class="bog-selection" aria-label="Selected recipients"></div>   <!-- hides itself while empty -->

<script>
  // Add one (an element or HTML) — plays the pop-in, opens the strip if it was empty
  BOG.selectionAdd(strip, '<div class="bog-action-item" data-value="nb">…avatar + remove button…</div>');
  // Remove one — or let the user tap its remove button ("actionitemremove" fires first)
  BOG.selectionRemove(strip.querySelector('[data-value="nb"]'));
</script>

Motion · Selection strip

An avatar pops in with a small overshoot when it's chosen and shrinks away when it's removed; the strip and the list below make room with a soft settle. Four cases, from the Avatars guide. Source: Avatars ↗

The pop-in and shrink as one modifier on each avatar, plus a strip that grows with a spring-like two-step. Removing uses SwiftUI's own layout animation for the gap.

A LazyRow with Modifier.animateItem() for the gap, an Animatable scale per avatar and an animated strip height.

Built into bog-ui.js: BOG.selectionAdd() / BOG.selectionRemove(), and the remove button.
