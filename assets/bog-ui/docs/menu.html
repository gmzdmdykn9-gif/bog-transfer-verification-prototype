Menu

Open in Figma ↗

A grey pill with a chevron (Onboarding OTP screen) that opens an iOS-style pull-down menu: blurred light panel, 17pt rows, a checkmark on the chosen row. The panel copies Apple's native menu on purpose, so it uses Apple's font and colors, not BOG tokens. Use it for a short switch like the code delivery method. For longer lists, use Select (it opens a Bottom Sheet).

Usage

<div class="bog-menu" id="otp-method">
  <button type="button" class="bog-menu__trigger" aria-haspopup="menu" aria-expanded="false">
    <span class="bog-menu__value">SMS კოდი</span>
  </button>
  <div class="bog-menu__panel" role="menu">
    <button type="button" class="bog-menu__item" role="menuitemradio" aria-checked="true" data-value="sms">SMS კოდი</button>
    <button type="button" class="bog-menu__item" role="menuitemradio" aria-checked="false" data-value="email">ელფოსტა</button>
    <button type="button" class="bog-menu__item" role="menuitemradio" aria-checked="false" data-value="whatsapp">WhatsApp</button>
  </div>
</div>

Selected row = aria-checked="true". On .bog-menu: data-align="start | end" (default centered). Events: menuchange (detail.value, detail.label). JS: BOG.selectMenu(el, value), BOG.closeMenu().
