BOG UI

Product Card

Open in Figma ↗

Card that shows one of the client's products (account, card, deposit…): title, Amount with balances, and a card / illustration / image on the right. Empty version shows a short message instead of the amount.

Usage

<div class="bog-product-card" role="button" tabindex="0">
  <div class="bog-product-card__info">
    <span class="bog-product-card__title">Account</span>
    <div class="bog-amount" data-size="medium">
      <div class="bog-amount__main"><span class="bog-amount__value">1,000.00</span><span class="bog-amount__currency">₾</span></div>
      <div class="bog-amount__balances">
        <span class="bog-amount__balance" data-active><span class="bog-amount__num">2.00</span>₾</span>
        <span class="bog-amount__balance"><span class="bog-amount__num">0.00</span>$</span>
      </div>
    </div>
  </div>
  <span class="bog-product-card__media" data-more><span class="bog-card-art" data-size="56"></span></span>
</div>
