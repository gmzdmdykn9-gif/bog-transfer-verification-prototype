BOG UI

Progress Tracker

Open in Figma ↗

Vertical list of the steps of a process users wait on (application, delivery): completed, current, warning, error and pending steps joined by a connector.

Usage

<div class="bog-progress-tracker">
  <p class="bog-progress-tracker__label">Label</p>                       <!-- optional -->
  <ol class="bog-progress-tracker__steps">
    <li class="bog-progress-tracker__step" data-status="completed">
      <span class="bog-progress-tracker__indicator"></span>
      <div class="bog-progress-tracker__content">
        <p class="bog-progress-tracker__title">Application sent</p>
      </div>
    </li>
    <li class="bog-progress-tracker__step" data-status="current">
      <span class="bog-progress-tracker__indicator"></span>
      <div class="bog-progress-tracker__content">
        <p class="bog-progress-tracker__title">Under review</p>
        <p class="bog-progress-tracker__helper">Helper text</p>         <!-- optional -->
        <p class="bog-progress-tracker__desc">Description</p>           <!-- optional -->
      </div>
    </li>
    <li class="bog-progress-tracker__step" data-status="warning">
      <span class="bog-progress-tracker__indicator"></span>
      <div class="bog-progress-tracker__content">
        <p class="bog-progress-tracker__title">Documents</p>
        <span class="bog-inline-message" data-status="warning" data-size="small">Message text</span>
      </div>
    </li>
    <li class="bog-progress-tracker__step">                             <!-- pending; last item has no connector -->
      <span class="bog-progress-tracker__indicator"></span>
      <div class="bog-progress-tracker__content">
        <p class="bog-progress-tracker__title">Money on the account</p>
      </div>
    </li>
  </ol>
</div>

step data-status     pending (default) | current | completed | warning | error
step data-indicator  icon | outline | number   (default: pending = outline, others = icon)
step data-connector  false  (hide the green connector of a completed step)
data-state           skeleton  (on the tracker or a single step)

Try it

Move through the steps: the circle color and the green connector animate when data-status changes.
