BOG UI

Sticky Bar

Open in Figma ↗

The bottom action area of a page or sheet: a fade from transparent to the surface color, an optional slot (Feedback, balances…), optional helper text, and one or two buttons (stacked, or an Icon Button + Button row), above the iOS home-indicator area. Page and Overlay placements, Themed and Static Black; Sticky Bar Amount adds a row of quick-amount buttons.

Usage

<div class="bog-sticky-bar" data-placement="page">
  <div class="bog-sticky-bar__slot">…optional: Feedback, balances…</div>
  <span class="bog-inline-message" data-size="small" data-icon="false">Message text</span>
  <div class="bog-sticky-bar__buttons">
    <button class="bog-btn" data-type="primary" data-width="fill">Primary</button>
    <button class="bog-btn" data-type="neutral" data-width="fill">Secondary</button>
  </div>
</div>

<!-- Button Layout=Row -->
<div class="bog-sticky-bar__buttons" data-layout="row">
  <button class="bog-icon-btn" data-type="neutral" aria-label="More"><span class="bog-icon"></span></button>
  <button class="bog-btn" data-type="primary" data-width="fill">Primary</button>
</div>

<!-- Sticky Bar Amount (Set value=False) -->
<div class="bog-sticky-bar__amounts">
  <button class="bog-btn" data-type="neutral" data-size="small">10 ₾</button>
  <button class="bog-btn" data-type="neutral" data-size="small">50 ₾</button>
  <button class="bog-btn" data-type="neutral" data-size="small">100 ₾</button>
  <button class="bog-btn" data-type="neutral" data-size="small">Total</button>
</div>

Optional parts: .bog-sticky-bar__slot (Slot — e.g. an inline .bog-feedback), the helper text (.bog-inline-message, small, no icon), the second button (Secondary action). The fade runs from transparent to the surface color over the top 20%, so content scrolls softly under the bar.
