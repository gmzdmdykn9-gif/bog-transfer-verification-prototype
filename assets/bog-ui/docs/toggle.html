BOG UI

Toggle Switch

Open in Figma ↗

On / off control that applies right away. Use the Toggle Switch + Label row so the whole row is one tap target. Themed only (Inverse Static not built).

Usage

<label class="bog-toggle-row">
  <span class="bog-toggle-row__caption">Label (optional)</span>
  <span class="bog-toggle-row__main">
    <span class="bog-toggle-row__text">
      <span class="bog-toggle-row__label">Toggle text</span>
      <span class="bog-toggle-row__desc">Description</span>
      <span class="bog-inline-message" data-status="negative">Message text</span>   <!-- data-validation="error" -->
    </span>
    <input type="checkbox" role="switch" class="bog-toggle">
  </span>
</label>
<!-- on the input: checked · disabled · aria-readonly="true" · data-indeterminate · data-state="skeleton" -->
