BOG UI

Radio Card

Open in Figma ↗

A bordered card that is one option of a single-choice group: optional leading slot, title, description and a radio button. Left or right aligned; Enabled, Pressed, Selected, Error, Read-only, Disabled and Skeleton.

Usage

<div class="bog-radio-card-group">
  <label class="bog-radio-card">
    <input type="radio" class="bog-radio-card__input" name="plan" value="basic" checked>
    <span class="bog-radio-card__box">
      <span class="bog-icon"></span>                                  <!-- optional leading slot -->
      <span class="bog-radio-card__content">
        <span class="bog-radio-card__title">Title</span>
        <span class="bog-radio-card__desc">Description</span>          <!-- optional -->
      </span>
      <span class="bog-radio-card__radio"></span>
    </span>
    <span class="bog-inline-message" data-status="negative">Message text</span>  <!-- shown with data-validation="error" -->
  </label>
</div>

Selected = checked on the input · Disabled = disabled · on .bog-radio-card: data-align="left", data-validation="error", data-state="readonly | skeleton | pressed". Radios with the same name form one group.
