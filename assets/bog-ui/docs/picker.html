BOG UI

Account Picker

Open in Figma ↗

Selectable account card. It's assembled from library parts: Amount (medium), account balances, and a UI Element in the media slot (card art, illustration or media circle). Currency chips use Country Flags. Put pickers in a .bog-picker-group to make them single-select.

Usage

<div class="bog-picker-group">
  <div class="bog-picker" data-selected>
    <div class="bog-picker__box" role="button" tabindex="0">
      <div class="bog-picker__head">
        <div class="bog-picker__info">
          <span class="bog-picker__title">Multi-currency Account</span>
          <div class="bog-amount" data-size="medium"><div class="bog-amount__main">
            <span class="bog-amount__value">1,000.00</span><span class="bog-amount__currency">₾</span>
          </div></div>
        </div>
        <span class="bog-card-art" data-size="56"><img src="card.png" alt=""></span>
      </div>
      <div class="bog-amount__balances">
        <span class="bog-amount__balance" data-active><span class="bog-amount__num">1,000.00</span>₾</span>
        <span class="bog-amount__balance"><span class="bog-amount__num">0.00</span>$</span>
      </div>
      <!-- optional: tap the card to expand and show the chips -->
      <div class="bog-picker__expand">
        <div class="bog-picker__chips">
          <button type="button" class="bog-currency-chip" aria-pressed="true">
            <span class="bog-flag" data-size="20"><img src="../assets/flags/ge.svg" alt=""></span>₾
          </button>
          …
        </div>
      </div>
    </div>
  </div>
</div>

Try it

Tap a multi-currency card: it gets selected and expands to show the currency chips (Figma Expandable). Tap it again to collapse. Opening another card closes the first. Tap a chip to switch currency.
