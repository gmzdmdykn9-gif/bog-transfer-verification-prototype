Account Picker

Open in Figma ↗

Selectable account card. It's assembled from library parts: Amount (medium), account balances, and a UI Element in the media slot (card art, illustration or media circle). Currency chips use Country Flags. Put pickers in a .bog-picker-group to make them single-select.

Try it

Tap a multi-currency card: it gets selected and expands to show the currency chips (Figma Expandable). Tap it again to collapse. Opening another card closes the first. Tap a chip to switch currency.

Motion

Chips check on and off, a card expands when selected and minimizes when another is picked, the page loads in, and an error shakes the list. The phone on the right plays all of it. Source: Component Motion Guidelines › Account Picker ↗

Drop-in pieces for each motion: a currency chip, the expanding card, the page entrance and the error shake. Each property gets its own withAnimation; two-step keyframes chain with completion (iOS 17+).

The same pieces in Compose, one Animatable per property.

Built into bog-ui.js: chips, Select / Minimize and the error shake run on their own. The page load is one call.
