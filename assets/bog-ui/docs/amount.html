Amount

Open in Figma ↗

Balance with currency symbol, optional currency selector and per-currency account balances. White static is shown on orange, Inverse on dark.

Usage

<div class="bog-amount" data-size="large">
  <button type="button" class="bog-amount__main">
    <span class="bog-amount__value">1,000.00</span>
    <span class="bog-amount__currency">₾</span>
    <span class="bog-amount__selector"></span>
  </button>
  <div class="bog-amount__balances">
    <span class="bog-amount__balance" data-active><span class="bog-amount__num">2.00</span>₾</span>
    <span class="bog-amount__balance"><span class="bog-amount__num">0.00</span>$</span>
  </div>
</div>
