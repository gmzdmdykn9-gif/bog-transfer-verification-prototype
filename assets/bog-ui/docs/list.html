BOG UI

List

Open in Figma ↗

List item rows for any list: left slot (UI Element), 1–3+ lines of text, right slot (amount, chevron, button…), dividers, and a group header. Used by Bottom Sheet and Select too.

Usage

<div class="bog-list-group">
  <div class="bog-list-group__header"><span>Accounts</span><span>Balance</span></div>
  <div class="bog-list" data-divider>
    <button type="button" class="bog-list-item">
      <span class="bog-icon-holder" data-size="40" data-type="outline"><span class="bog-icon"></span></span>
      <span class="bog-list-item__content">
        <span class="bog-list-item__subtitle">Subtitle</span>
        <span class="bog-list-item__label">Primary Label</span>
      </span>
      <span class="bog-list-item__end"><span class="bog-list-item__value">0.00 ₾</span></span>
      <span class="bog-list-item__chevron"></span>
    </button>
  </div>
</div>

The layout follows what you put in the content: 1 Line label · 2 Line subtitle + label · 2 Line Reverse label + subtitle · 3 Line subtitle + label + secondary · 3 Line+ label + subtitle + extra (badge, message).

Layouts × states

Left and right slots

Left: any UI Element at 40. Right: amount text, 2-line text, chevron, UI Elements or a small Icon Button.
