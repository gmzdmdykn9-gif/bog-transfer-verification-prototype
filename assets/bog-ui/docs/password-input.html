BOG UI

Password Input

Open in Figma ↗

Text Input with a show / hide eye, plus the Password Requirements checklist.

Usage

<div class="bog-field bog-password-input">
  <label class="bog-field__box">
    <span class="bog-field__text">
      <span class="bog-field__label">Enter Password</span>
      <input class="bog-field__input" type="password" placeholder=" " id="pw">
    </span>
    <button type="button" class="bog-password-input__toggle" aria-label="Show password" aria-pressed="false"></button>
  </label>
  <p class="bog-field__message">Message text</p>
</div>

<div class="bog-password-rules" data-for="pw">
  <p class="bog-password-rules__label">Password must contain:</p>
  <ul class="bog-password-rules__list">
    <li class="bog-inline-message" data-size="small" data-pattern=".{6,}">At least 6 characters</li>
    <li class="bog-inline-message" data-size="small" data-pattern="[A-Z]">At least one uppercase letter</li>
  </ul>
</div>

Try it

Type a password: requirements turn green as they're met, and the unmet ones turn red when you leave the field. Tap the eye to show the password.
