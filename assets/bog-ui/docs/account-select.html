BOG UI

Account Select

Open in Figma ↗

A Select for choosing an account: card/account visual on the right, larger account name once chosen, favorite star. Tapping opens a Bottom Sheet of Account Pickers.

Usage

<div class="bog-select" data-variant="account" data-sheet="accounts-sheet">
  <button type="button" class="bog-select__box">
    <span class="bog-select__text">
      <span class="bog-select__label">Account<span class="bog-select__fav"></span></span>
      <span class="bog-select__value"></span>
    </span>
    <span class="bog-card-art" data-size="40"></span>
    <span class="bog-select__chevron"></span>
  </button>
</div>

<!-- The sheet lists Account Pickers; data-value/data-label fill the Select -->
<div class="bog-sheet" id="accounts-sheet" hidden> …
  <div class="bog-picker" data-value="acc-1" data-label="Main account">…</div>
</div>

Try it

Tap the field: a Bottom Sheet with Account Pickers opens; pick one to fill the field.
