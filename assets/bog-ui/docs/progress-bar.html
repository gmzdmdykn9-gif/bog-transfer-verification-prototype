BOG UI

Progress Bar

Open in Figma ↗

Read-only bar toward a known end (savings goal, spending limit, steps of a short flow). Single or Segmented, 5 types, Thin / Thick.

Usage

<!-- Single: set --value (and aria-valuenow); the fill animates -->
<div class="bog-progress" data-type="accent" data-size="thin" role="progressbar"
     aria-valuemin="0" aria-valuemax="100" aria-valuenow="40" style="--value: 40%">
  <span class="bog-progress__bar"></span>
  <div class="bog-progress__labels">                 <!-- optional (Text) -->
    <div class="bog-progress__start">
      <span class="bog-progress__label">400.00 ₾</span>
      <span class="bog-progress__helper">Saved</span>
    </div>
    <div class="bog-progress__end">
      <span class="bog-progress__label">1,000.00 ₾</span>
      <span class="bog-progress__helper">Goal</span>
    </div>
  </div>
</div>

<!-- Segmented: 2–10 segments, reached ones get data-state="filled" -->
<div class="bog-progress" data-progress="segmented" role="progressbar" aria-valuemin="0" aria-valuemax="4" aria-valuenow="2">
  <span class="bog-progress__bar">
    <span class="bog-progress__segment" data-state="filled"></span>
    <span class="bog-progress__segment" data-state="filled"></span>
    <span class="bog-progress__segment"></span>
    <span class="bog-progress__segment"></span>
  </span>
</div>

data-progress   single (default) | segmented
data-type       accent (default) | positive | warning | negative | neutral-inverse
data-size       thin (default, 4px) | thick (8px)
data-state      skeleton
data-material   ultrathin  (iOS Ultrathin material behind the rail)

Try it

The fill animates when --value changes (Single) or when a segment gets data-state="filled" (Segmented).
