BOG UI

Keypad

Open in Figma ↗

Number pad that types into a Code Input (data-for). Desktop number keys and Backspace work too. From Figma Onboarding › Verification states › passcode.

Usage

<div class="bog-keypad" data-for="passcode">
  <button type="button" class="bog-keypad__key" data-key="1">1</button>  <!-- … 9 -->
  <span class="bog-keypad__key" aria-hidden="true"></span>
  <button type="button" class="bog-keypad__key" data-key="0">0</button>
  <button type="button" class="bog-keypad__key" data-key="back" aria-label="Delete"><span class="bog-keypad__back"></span></button>
</div>
