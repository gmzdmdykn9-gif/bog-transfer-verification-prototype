BOG UI

Select

Open in Figma ↗

Looks like a Text Input with a chevron. Tapping it opens a Bottom Sheet with the options; picking one fills the Select and closes the sheet. List the options in a hidden native <select> and the sheet is built automatically, or point it at your own sheet for custom rows (flags, subtitles).

Usage

<!-- Quickest: options in a hidden native <select>; the bottom sheet is built for you -->
<div class="bog-select">
  <button type="button" class="bog-select__box">
    <span class="bog-select__text">
      <span class="bog-select__label">Country</span>
      <span class="bog-select__value"></span>
    </span>
    <span class="bog-select__chevron"></span>
  </button>
  <select class="bog-select__native" name="country">
    <option value="GE">Georgia</option>
    <option value="US">United States</option>
  </select>
</div>

<!-- Custom sheet (flags, subtitles…): point data-sheet at a Bottom Sheet whose
     .bog-list-item options have data-value -->
<div class="bog-select" data-sheet="currency-sheet"> …same button… </div>
<div class="bog-sheet" id="currency-sheet" hidden> …
  <button type="button" class="bog-list-item" data-value="GEL">
    <span class="bog-flag" data-size="32"><img src="bog-ui/assets/flags/ge.svg" alt=""></span>
    <span class="bog-list-item__content"><span class="bog-list-item__label">GEL</span></span>
  </button> …
</div>
