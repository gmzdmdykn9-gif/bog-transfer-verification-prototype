BOG UI

Keyboard Numeric

Open in Figma ↗

Number pad (56px pads with a pressed background) with an optional bottom-left pad — Face ID, fingerprint or Dot — and backspace. Themed, White Static, Black Static and Invert. Types into a PIN code Input, a Code Input or an amount field; desktop keys work too. Replaces the old Keypad.

Usage

<div class="bog-pin" id="pin">…</div>            <!-- or a .bog-code, or a field with an <input> -->
<div class="bog-numpad" data-for="pin">         <!-- data-appearance="white|black|invert" · data-biometric="fingerprint" -->
  <button type="button" class="bog-numpad__key" data-key="1">1</button> … 9
  <button type="button" class="bog-numpad__key" data-key="biometric" aria-label="Face ID"></button>
    <!-- or data-key="dot" aria-label="Decimal point" · or <span class="bog-numpad__key"></span> (no pad) -->
  <button type="button" class="bog-numpad__key" data-key="0">0</button>
  <button type="button" class="bog-numpad__key" data-key="back" aria-label="Delete"></button>
</div>
<!-- events: numpadbiometric (on .bog-numpad) · pinchange / pincomplete (on .bog-pin) · codechange / codecomplete (on .bog-code) -->
