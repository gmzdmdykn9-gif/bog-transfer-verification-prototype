Code Input

Open in Figma ↗

Cells for an SMS code or a passcode. With an input it follows the phone keyboard and SMS autofill; with a Keypad it follows the keypad. Empty cells are from Figma (Onboarding › Verification states); Filled, Active and Error are prototype additions.
