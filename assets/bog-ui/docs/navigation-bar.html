BOG UI

Navigation Bar

Open in Figma ↗

The top bar of a screen: a status bar mockup (iOS or Android), an optional back button or media on the left, a title (with optional secondary text or caption) and up to two Icon Buttons, a Button or a timer on the right. Themed, White Static and Black Static appearances; optional divider and background, which can also appear automatically when the content scrolls.

Usage

<header class="bog-nav-bar" data-platform="ios" data-sticky data-scroll-effect>
  <div class="bog-nav-bar__status"></div>
  <div class="bog-nav-bar__header">
    <button class="bog-icon-btn" data-type="neutral" data-size="small" aria-label="Back"><span class="bog-icon" data-icon="chevron-left"></span></button>
    <div class="bog-nav-bar__title">
      <h1 class="bog-nav-bar__heading">Title</h1>
      <span class="bog-nav-bar__subtitle">Secondary text</span>
    </div>
    <div class="bog-nav-bar__actions">
      <button class="bog-icon-btn" data-type="neutral" data-size="small" aria-label="Edit"><span class="bog-icon"></span></button>
      <button class="bog-icon-btn" data-type="neutral" data-size="small" aria-label="Chat"><span class="bog-icon" data-icon="chat"></span></button>
    </div>
  </div>
</header>
Attribute (on .bog-nav-bar)ValuesFigma
data-platformios (default, 44px status bar) · android (24px)Platform
data-appearancethemed (default) · white · blackAppearance = Themed / White Static / Black Static
data-status-bar="false"hide the status bar mockupStatus Bar = False
data-divider1px line under the barDivider = True
data-backgroundlayer_01 fillBackground = True
data-stickystick to the top of the scroll container—
data-scroll-effectbackground + divider appear once the content is scrolled (bog-ui.js)Divider + Background

Left slot: a small neutral Icon Button (back) or a .bog-media-circle data-size="32". Title: __heading alone, + __subtitle (Title + Secondary text), or __caption before it (Caption + Title). Right slot (__actions): 1–2 small Icon Buttons (with optional .bog-badge-dot), a small Button, or .bog-nav-bar__timer. Item types per appearance: Themed → data-type="neutral", White Static → data-type="white", Black Static → data-type="black-secondary".
