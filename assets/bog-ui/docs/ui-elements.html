BOG UI

UI Elements

Open in Figma ↗

Visual slots that other components (list items, pickers, cards…) place in their leading or trailing position. Use these whenever a design shows a flag, photo, illustration, bank card, icon circle or counter. data-size is the height from the Figma size name ("Medium 32" → data-size="32").
