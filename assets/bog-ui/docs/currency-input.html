BOG UI

Currency Input

Open in Figma ↗

Amount field with a currency symbol and a currency picker (flag + code) that opens a Bottom Sheet. Selectable, fixed or hidden currency; every Text Input state. Plus the compact 96px Currency Small Input.

Usage

<div class="bog-field bog-currency-input">
  <label class="bog-field__box">
    <span class="bog-field__text">
      <span class="bog-field__label">Amount</span>
      <span class="bog-currency-input__value">
        <input class="bog-field__input" inputmode="decimal" placeholder="0.00">
        <span class="bog-currency-input__symbol">₾</span>
      </span>
    </span>
    <button type="button" class="bog-currency-input__currency" data-sheet-open="currency-sheet">
      <span class="bog-flag" data-size="16"><img src="bog-ui/assets/flags/ge.svg" alt=""></span>GEL
    </button>
  </label>
</div>
<!-- sheet rows: <button class="bog-list-item" data-currency="USD" data-symbol="$" data-flag="…/us.svg">…</button> -->

<div class="bog-currency-small">
  <label class="bog-currency-small__box">
    <input class="bog-currency-small__input" inputmode="decimal" placeholder="0.00">
    <span class="bog-currency-small__symbol">₾</span>
  </label>
</div>
