Modal Dialog

Open in Figma ↗

Centered dialog over a dim background: Standard, Minimal, Cover and Destructive.

Usage

<button class="bog-btn" data-type="primary" data-modal-open="my-modal">Open</button>

<div class="bog-modal" id="my-modal" hidden>
  <div class="bog-modal__dialog" role="dialog" aria-modal="true" aria-labelledby="my-modal-title">
    <header class="bog-modal__header">
      <h2 class="bog-modal__title" id="my-modal-title">Modal dialog</h2>
      <button type="button" class="bog-icon-btn" data-type="neutral" data-size="small" aria-label="Close" data-modal-close><span class="bog-icon" data-icon="close"></span></button>
    </header>
    <div class="bog-modal__body">
      <p class="bog-modal__text">Body text</p>
    </div>
    <footer class="bog-modal__footer">
      <button type="button" class="bog-btn" data-type="primary" data-size="medium">Confirm</button>
      <button type="button" class="bog-btn" data-type="neutral" data-size="medium" data-modal-close>Cancel</button>
    </footer>
  </div>
</div>

<!-- Minimal: no header -->
<div class="bog-modal__body" data-layout="minimal"><p class="bog-modal__text">…</p><button … data-modal-close>X</button></div>
