OTP Verification

Open in Figma ↗

The block for typing a one-time code: an optional SMS / Email choice, the code field, where the code went, a resend timer and a Resend button. It is made of library parts: Radio Button Group, Text Input, Inline Message and a Ghost Small Button. States: Default, Resend, Loading, Expired, plus Hard (hardware token) and Skeleton, each in Themed and Inverse Static.

Figma propertyAttribute on .bog-otp
State = Default / Resend / Loading / Expiredno attribute · data-state="resend | loading | expired". Use BOG.setOtpState(el, state) so Loading also disables the inputs and the button.
Verification Method = Harddata-method="hard": message only, no timer or button
Appearance = Inverse Staticdata-appearance="inverse", also on the field, radio group, inline message and button
Skeleton = Truedata-skeleton
Selector / Timer-Resend = Falseleave out the radio group / the .bog-otp__timer

Behavior (bog-ui.js): data-timer="35" counts down, then hides the timer and switches to Resend. Resend clears the field, restarts the timer and fires otpresend. Typing all digits fires otpcomplete (detail.value). On iPhone, autocomplete="one-time-code" suggests the code from the SMS.
