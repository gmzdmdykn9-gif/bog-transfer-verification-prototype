BOG UI

PIN code Input

Open in Figma ↗

Title, helper text and four dots for a PIN or passcode, typed on a Keyboard Numeric. Default, Filled and Error (red helper and dots).

Usage

<div class="bog-pin" id="pin">
  <div class="bog-pin__text">
    <p class="bog-pin__title">Enter your PIN</p>
    <p class="bog-pin__helper">Please enter your 4-digit code</p>
  </div>
  <div class="bog-pin__dots"><span class="bog-pin__dot"></span><span class="bog-pin__dot"></span><span class="bog-pin__dot"></span><span class="bog-pin__dot"></span></div>
</div>
<div class="bog-numpad" data-for="pin">
  <button type="button" class="bog-numpad__key" data-key="1">1</button> … 9
  <button type="button" class="bog-numpad__key" data-key="biometric" aria-label="Face ID"></button>
  <button type="button" class="bog-numpad__key" data-key="0">0</button>
  <button type="button" class="bog-numpad__key" data-key="back" aria-label="Delete"></button>
</div>

PIN: data-validation="error" (put the error text in the helper), events pinchange / pincomplete, BOG.setPin(el, value). Numpad: data-for = a .bog-pin or .bog-code, data-biometric="fingerprint", event numpadbiometric. Not built yet: White / Black Static and Invert appearances, Dot pad.
