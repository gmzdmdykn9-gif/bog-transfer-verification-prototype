BOG UI

Action Card

Open in Figma ↗

Tappable bordered card: a UI Element on the left, title and secondary text, optional status message or extra content, chevron on the right. Use a group to stack them or scroll them sideways.

Usage

<button type="button" class="bog-action-card">
  <span class="bog-icon-holder" data-size="40"><span class="bog-icon"></span></span>
  <span class="bog-action-card__content">
    <span class="bog-action-card__title">Primary text</span>
    <span class="bog-action-card__text">Secondary text</span>
  </span>
  <span class="bog-action-card__chevron"></span>
</button>

<!-- a list of cards (12px apart), or a horizontal scroller -->
<div class="bog-action-card-group"> …cards… </div>
<div class="bog-action-card-group" data-horizontal> …cards… </div>

Variants

Leading slot options

Any UI Element at size 40 (Figma "Action Card Slot").
