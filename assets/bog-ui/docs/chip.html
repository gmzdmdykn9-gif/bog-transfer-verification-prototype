Chip

Open in Figma ↗

Compact buttons for quick actions, suggestions and filters: Assist, Suggestion (incl. 2-line), Filter (with selected state and overlay placement) and Icon-only chips, plus single-row or wrapping groups.

Usage

<button type="button" class="bog-chip">Chip text</button>
<button type="button" class="bog-chip" data-type="filter" aria-pressed="true">Last 30 days</button>
<button type="button" class="bog-chip" data-type="icon" aria-pressed="false" aria-label="Filters">
  <span class="bog-icon"></span><span class="bog-chip__count">4</span>
</button>

<div class="bog-chip-group">…chips in one scrolling row…</div>
<div class="bog-chip-group" data-wrap>…chips on multiple rows…</div>
